# SEAM Photo

A fast, smooth Android gallery focused on instant browsing of photos and videos.

## Current features
- All Photos view with newest media first
- Photos + videos from Android MediaStore
- Beautiful album grid with cover thumbnails
- Pinch gesture to make the media grid larger or smaller (2–6 columns)
- Dark / Light theme toggle
- Lazy grid rendering and background MediaStore scanning for smooth scrolling/startup
- Video thumbnail support
- Android 13+ media permissions and legacy Android support

## Package
`ir.seam.photo`

## Build
Open the project in Android Studio and run the `app` configuration, or use the included GitHub Actions workflow to build a debug APK artifact.
